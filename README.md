# IST105-Assignment5: Interactive Treasure Hunt (Django)

This is a simple Django web app with three puzzles:
- **Number Puzzle:** Enter a number, get its square root (if even) or cube (if odd).
- **Text Puzzle:** Enter text, see its binary and vowel count.
- **Treasure Hunt:** Guess a random number (1-100) in up to 5 tries, with hints.

## How to run
1. Install requirements: `pip install -r requirements.txt`
2. Run migrations: `python manage.py migrate`
3. Start server: `python manage.py runserver`
4. Open [http://localhost:8000](http://localhost:8000)

## Deployment
- Ready for deployment on GitHub and AWS (EC2, Elastic Beanstalk, etc.)
